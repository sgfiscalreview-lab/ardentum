# Ardentum 1.0.0

Ardentum is a free web platform for building, optimising, simulating and backtesting
investment portfolios, with the mathematics, assumptions and limitations behind every
result. Live at https://ardentum-frontend.pages.dev.

## Highlights

- **Optimise under real constraints.** Minimum volatility, maximum Sharpe, target
  return or volatility, mean-variance utility and minimum CVaR, with position, sector,
  exposure, tracking-error and ESG limits. Every solution is checked against every
  constraint, and infeasible requests explain what to change.
- **Estimate with care.** Shrinkage estimators (Bayes-Stein means, Ledoit-Wolf
  covariance) and Black-Litterman views, because sample estimates are noisy.
- **See the trade-offs.** Mean-variance, ESG-efficient and mean-CVaR frontiers; risk
  decomposition; which constraints bind and why each holding is there.
- **Test honestly.** Walk-forward backtests that only ever see past data, with
  trading costs and attribution; seeded Monte Carlo with contributions and
  withdrawals.
- **Real data.** US industry returns since 1926 (Kenneth R. French Data Library),
  ECB exchange rates, BIS policy rates for currency hedging, and open ESG scores from
  WikiRate, each credited on the Licences page.
- **Reproducible research.** Three studies in `research/` rerun from public data by
  a GitHub workflow.
- **Open to everyone.** A guided tour runs on demo data with no sign-in, and public,
  anonymous usage counts show how much the platform is used.

## Verification

- About 350 backend tests check each calculation against closed forms or independent
  references (SciPy, scikit-learn, PyPortfolioOpt, brute force, KKT conditions) and
  check that backtests cannot see the future.
- The API tests also run on PostgreSQL; 52 end-to-end browser tests cover every
  workflow, accessibility in light and dark themes, and phone-width layouts.
- A daily workflow checks the live site and API.

The validation approach for each method is documented in
`docs/methodology/09-validation.md`.

## Known limitations

- The API runs on a free hosting tier and can take up to a minute to wake after a
  quiet period.
- Individual stocks and funds need a licensed market-data key (Tiingo); the free
  build uses industry portfolios, currencies and uploaded CSV files.
- Ardentum is for education and research and does not give investment advice.
